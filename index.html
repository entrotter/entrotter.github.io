THE SOFTWARE, NOT THE SCI-FI

Rewind state.
Not reality.

“Time machine” is a useful metaphor. Re-executing actions on a fork is not the same as reconstructing the future of an entire economy.

RUNNABLE OFFLINE

Synthetic stress tests

Compare causal policies on an explicit price path. Include fees, slippage and drawdown. No API key, wallet or cloud account.

REAL FORK VERIFIED

Isolated EVM branches

An Anvil adapter runs supplied actions in paired local processes. Source pins, overrides and receipts belong in the report.

CONTRIBUTOR-FRIENDLY

Evidence you can inspect

Versioned JSON, a small Python SDK, a CLI and six focused repositories. No proprietary backend required to run the offline example.
