      Limits of this replay
      Only Ethereum Shanghai legacy/type-1/type-2 prefixes of up to 32 transactions are supported. Anvil pool admission can reject valid same-block funding dependencies and leave the baseline unverified. Original in-prefix oracle updates remain; later transactions and external responses are not invented. Full-block, opcode, state-root and end-withdrawal equivalence remain open. The v0.1 agent explorer is separate. This browser checks display consistency and integrity; it never executes transactions.
